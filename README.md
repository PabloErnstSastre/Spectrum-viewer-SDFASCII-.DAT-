HP 35670A Spectrum Viewer

A tool for reading, interpreting, processing, and visualizing SDF binary files (.DAT) generated by the Hewlett-Packard HP 35670A Dynamic Signal Analyzer.

HP 35670A Spectrum Viewer is a project developed to facilitate the recovery and analysis of measurements recorded by the HP 35670A Dynamic Signal Analyzer. It allows users to visualize binary .DAT files directly, without relying on the original instrument software.

The project includes two implementations: a web-based viewer developed in HTML, CSS, and JavaScript, and a desktop application developed in Python.

Main Features

SDF binary file reading (.DAT): interpretation of measurement data and metadata stored in the analyzer's original files, using the sdfascii library as a reference alongside additional decoding tools.

Automatic measurement type recognition: identification and specific processing of linear spectra, orbits, and calculated traces, including functions such as DJOM(SQRT(PSPEC)).

Up to four simultaneous spectra: each panel allows users to load and configure an independent trace.

Signal representations: Real (I), Imaginary (Q), Magnitude, Complex Modulus, LogMag, dB, Phase, Unwrapped Phase, Polar, Vector (Nyquist), and other representations.

Amplitude unit selection: linear spectra can be displayed in RMS, Peak, or Peak-to-Peak values.

Measurement-specific processing: application of channel correction factors, engineering unit conversions, and mathematical transformations according to the measurement type, avoiding incorrect processing of traces that have already been calculated.

Engineering units: amplitude representation in mm, mm/s, or mm/s², depending on the measurement.

Axis configuration: independent adjustment of minimum and maximum limits, scales, and display ranges.

Interactive markers: users can add and drag markers across plots to identify frequencies, amplitudes, and relevant measurement points.

Custom plot titles: each spectrum can display its original trace name alongside an additional user-defined title.

Results export: printing and PDF generation in A4 format, including plots, titles, and markers.

Available Versions

1. Web Viewer (HTML / JavaScript)

A standalone local application that runs directly in a web browser without requiring Python installation. It integrates SDF file reading, spectrum visualization, graph configuration, interactive markers, and PDF printing.

2. Desktop Application (Python)

A graphical desktop application developed using PySide6, Matplotlib, and NumPy, with pandas as an auxiliary tool for data management and export.

It includes the main features of the web viewer and allows the software to be used as an independent Windows application. The project includes scripts for installing dependencies, launching the application, and building a standalone executable.

Project Goals

The main goal is to provide an independent tool for interpreting and visualizing original binary records from the HP 35670A, facilitating vibration analysis and dynamic signal processing without relying on proprietary acquisition software.

The project also aims to document and reproduce the mathematical processing required to convert the values stored in binary files into the measurement quantities displayed by the analyzer.
